## 2. 仍需验证的决策

1. AstrBot 当前版本可提供哪些稳定的 Agent/hook/发送回执入口，是否能够在不重复写历史的前提下接管样板路径。实现前按实际 API 验证。
2. owner_key 的领域 Schema、来源主体映射和旧数据归属需要逐表设计。当前 scope_key 包含绑定 revision，本轮未改代码，也不能据此断言现有持久数据已经丢失。
3. 原生插件的最小边界与首期联动场景已纳入设计，阶段 0 需逐项补齐真实入口、Schema 和用例样本，阶段 1 完成适配验证；完整内部设计和存量迁移分批推进。本文新增的覆盖表不代表已完成运行接入。
4. CPU、内存、页面首屏和模型成本的发布阈值需在指定部署环境测量后确定；不以未经测试的百分比宣称优化。
5. 外部参考项目需补仓库 URL、commit、许可证与独立验证记录，才能用于实现选型。
