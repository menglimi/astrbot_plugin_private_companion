# 多站点额度看板（Quota Watch）

在「陪伴小屋 → 模型与连接 → **额度看板**」中，你可以集中查看所有中转站与官方模型 API 的剩余额度、健康状态、单次消耗以及关联供应商的近期调用统计，并可灵活反哺到陪伴角色的「余额感知」与主动低余额提醒。

> 致谢：多站点查额度协议适配与智能站点引导的思路参考自 `quota-watch`（`mofei-114`）。

## 一、两步式智能添加向导

点击右上角 **「+ 添加站点」** 或 **「从 AstrBot 导入」** 即可打开两步引导弹窗：

1. **第一步 · 来源与自动识别**
   - **从已有 AstrBot 供应商复用**：直接从 AstrBot 已配置的模型供应商列表中点选，后端直接复用其地址、API Key 与代理，前端不回显或复制任何密钥。
   - **手动输入站点地址**：输入站点根地址（例如 `https://api.example.com`），点击 **「自动识别站点类型」**。
   - 自动探测会自动识别官方域名（如 DeepSeek、OpenRouter、硅基流动、月之暗面），以及 NewAPI / OneAPI / VoAPI / RixAPI / Veloera 等兼容站点的 `/api/status` 与所需用户 ID 请求头（如 `New-Api-User`、`Rix-Api-User`、`Veloera-User`）。
   - 如果站点较特殊或未公开状态接口，可直接点击下方预设标签手动切换协议类型。

2. **第二步 · 按站点类型精简填写**
   - 表单只展示该站点协议真正需要的字段，避免无关选项堆砌：
     - **官方 API 站点**（DeepSeek / OpenRouter / 硅基流动 / 月之暗面 / Sub2API / OpenAI 兼容账单）：如已选择「从 AstrBot 供应商复用」，无需重复填写 API Key，直接测试并保存即可。
     - **NewAPI / OneAPI 标准站**：填写个人访问令牌（需 `profile:read` 权限，非 `sk-` 模型 Key）。
     - **NewAPI 衍生站 / 需用户 ID 站**（如 RixAPI / Veloera / 部分魔改 NewAPI 站）：除访问令牌外，提供「用户 ID」与对应请求头选择，并支持「使用账号密码临时换取系统访问令牌」（登录密码仅在内存中请求一次，绝不落盘保存）。
     - **自定义脚本**：复用原有 QuickJS 沙盒 `request + extractor(response)` 格式，支持任意私有或小众站点。
   - **自愈闭环**：点击 **「测试连接并预览余额」** 时，如果 NewAPI 站点明确返回缺少用户 ID（如 `New-Api-User` / `Rix-Api-User`），向导会自动切换到带用户 ID 的模式、预填服务端要求的请求头名称，并高亮聚焦「用户 ID」输入框。

## 二、支持的站点类型一览

| 适配器 ID | 名称 | 鉴权方式 | 支持能力 |
| --- | --- | --- | --- |
| `newapi` | NewAPI / OneAPI 标准站 | 个人访问令牌（非 `sk-`） | 余额、已用、总额、最近一次消耗、币种与倍率 |
| `newapi_user_id` | NewAPI 衍生站 / 需用户 ID 站 | 访问令牌 + 用户 ID 请求头（支持一次性登录换取） | 同上，自动兼容 `New-Api-User` / `Rix-Api-User` / `Veloera-User` |
| `deepseek` | DeepSeek 官方 | 模型 API Key（可零配置复用 AstrBot） | CNY / USD 余额、赠送与充值明细 |
| `openrouter` | OpenRouter 官方 | API Key（可零配置复用 AstrBot） | 余额、已用、总额（优先 `/credits`，自动回退 `/auth/key`） |
| `siliconflow` | 硅基流动官方 | API Key（可零配置复用 AstrBot） | 可用余额、赠送余额与总余额（CNY） |
| `moonshot` | 月之暗面（Kimi）官方 | API Key（可零配置复用 AstrBot） | 可用余额、代金券与现金余额（CNY） |
| `sub2api` | Sub2API / 订阅中转站 | API Key（可复用 AstrBot） | 剩余额度、总额、已用与套餐信息 |
| `openai_billing` | OpenAI 兼容账单接口 | API Key（可复用 AstrBot） | 兼容 `/dashboard/billing` 总额与已用查询 |
| `custom_script` | 自定义脚本 | QuickJS 沙盒模板变量 | 任意自定义 HTTP + JSON 提取 |
| `unsupported_official` | 不提供公开余额接口的官方平台 | — | 对 Anthropic / Gemini / xAI 等给出明确说明 |

## 三、汇率汇总、双单位切换与套餐余量

- **站内币种与四模式换算**：支持 NewAPI 系站点的 `USD`、`CNY`（按站内 `usd_exchange_rate`）、`CUSTOM` 自定义币种（按站内 `custom_currency_exchange_rate` 与自定义符号，并支持从站点充值配置 `/api/user/topup/info` 自动推断或手动覆盖法币参考换算）及 `TOKENS` 原始计数四模式，统一作用于余额、已用、总额与最近一次消耗。
- **自定义币种双单位一键切换**：对于支持自定义符号与法币换算的站点，卡片余额行提供内联双单位切换按钮（例如 `🍪 ↔ ¥`），可就地平滑切换主/副显示并静默持久化偏好，无需重绘整页。
- **活跃订阅套餐子行**：自动读取 NewAPI 系站点 `/api/subscription/self` 活跃套餐（可选，不支持时静默跳过），在卡片金额下方展示有效订阅余量与套餐数量，不与钱包主余额混算。
- **严禁直接相加不同币种**：额度看板从「模型与连接 → 计价与汇率」读取统一展示币种（CNY / USD）与实时汇率，对现金站点按汇率精确折算汇总，并清晰展示 CNY / USD 分币种明细；非现金积分（如 `CREDIT` / `TOKENS`）单独计数，不与法币混算。
- **卡片状态色阶**：
  - 正常（鼠尾草绿）：余额高于偏低阈值。
  - 偏低 / 告急（暖琥珀 / 柔和珊瑚红）：低于单站或全局告警阈值，同时在顶部标签角标汇总提醒。
  - 异常：展示清晰脱敏原因与一键修复按钮（如「补填用户 ID」「更新令牌」）。

## 四、陪伴「余额感知」、一键主站与上游对账

- **一键设为主站与全局直达**：额度看板顶部概览卡直接展示当前生效主站，卡片提供 `★ 主站 / 默认主站` 徽标与一键 **「设为主站」** 快捷操作；全局搜索支持通过 `额度看板`、`edkb`、`主站`、`指定主站`、`zhuzhan` 等关键词直达额度看板或感知主站配置项。
- **维护页余额卡片联动**：维护页「Token 用量」顶部的账户余额卡片自动展示多站点感知主站名称与状态徽标，支持点击卡片或 **「额度看板 ↗」** 直接跳转至额度看板，并与「重新查询」按钮互不干扰。
- **中转站上游账单只读对照**：维护页「Token 用量」底部提供默认折叠的「中转站上游账单对照（只读）」抽屉，展开后按需读取 NewAPI 系站点的 `/api/log/self`（最多 5 页 / 200 条，5 分钟缓存），展示钱包实扣、订阅套餐实扣、上游缓存命中率与实扣分组倍率，并支持按 API 密钥筛选；数据严格为站点账号级只读对照，绝不计入角色本地账本与预算。
- **多站点感知策略**：点击概览卡片中的 **「配置感知策略」**，可以决定陪伴角色在主动低余额提醒与私聊被问余额时如何读取多站点数据：

  - **指定单个主站点（`primary`）**：兼容经典单站行为，指定一个主站（或自动取首个参与感知的启用站点）。
  - **勾选站点按汇率折算汇总（`aggregate_sum`）**：将所有勾选参与感知的现金站点按实时汇率折算到目标币种后合计，统一触发低余额提醒。
  - **任一勾选站点偏低即提醒（`any_low`）**：只要任意勾选站点达到偏低/告急阈值（或取最低余额站点），即优先上报该站点状态。

> 说明：原有「感知 → 余额感知」单站配置完全保留；若你尚未在额度看板新建站点，看板会自动只读投影原有单站数据源，等你新增首个站点后再平滑切换为多站点管理。

## 五、安全与隐私边界

- **SSRF 防护**：默认强制 HTTPS、禁用自动重定向、拦截私网与云元数据地址（即使针对局域网自建站勾选「允许内网 / HTTP」，仍永久屏蔽 `169.254.169.254` 等云元数据地址）。
- **零密码存储**：一次性账号登录换取令牌仅在请求瞬间使用密码，内存立即清空且绝不写入磁盘或日志。
- **凭据脱敏与备份保护**：所有接口永不回传明文令牌或代理密码；导出脱敏备份时自动剔除 `auth_token` 与 `proxy_url`。
- **安全图标缓存与官方品牌徽标**：站点头像按「`/api/status` 图标 → 首页 `<link rel="icon">` / `apple-touch-icon` → `/logo.png` → `/favicon.ico` → `api.*` 主站回退」自动获取（仅无凭据公开请求允许最多 2 跳且逐跳重验 SSRF 的重定向）；服务端对栅格图片（≤1 MiB）执行魔数校验，对 SVG（≤64 KiB）执行严格 XML 白名单静态净化（剔除/拦截脚本、`foreignObject`、动画、事件属性与外部引用），并通过 base64 在 `<img>` 隔离上下文中展示；官方站点离线时自动回退至主题适配的内置单色矢量品牌徽标。
