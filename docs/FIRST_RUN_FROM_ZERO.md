# 首次使用：从零到跑通

面向刚装好 AstrBot、只配好了人格的新用户。按顺序做完即可；不需要改任何代码或数据库。

## 0. 开始前确认

- [ ] AstrBot 版本至少为 4.27.2（4.24.9 等旧版不满足插件 7.1.3 的运行要求）
- [ ] AstrBot 能正常收发 QQ 私聊（平台适配器在线）
- [ ] AstrBot「模型提供商」里有可用的文本模型，主链对话能回复
- [ ] 人格已在「人格设定」里创建/导入，并确认是当前 Bot 使用的人格

插件只增强陪伴能力，日常回复仍走 AstrBot 主链；这三件事不满足，后面会卡住。

## 1. 安装插件

- 面板 →「插件」→ 安装 `astrbot_plugin_private_companion`（插件市场，或上传仓库 zip）；
- 安装后重载插件，确认无加载报错；
- 左侧「插件页面」应出现 **我会永远陪着你**（陪伴小屋）。

要求：AstrBot ≥ 4.27.2，插件 7.1.3。若使用 AstrBot 4.29.4 且页面接口全部 404，先按 issue #555 排查，不要继续往下配。

## 2. 绑定核心管理员窗口

1. 用你自己的 QQ 私聊 Bot，发送：

   ```text
   我会永远陪着你
   ```

   想同时指定人格：

   ```text
   我会永远陪着你 晚星
   ```

2. 打开「陪伴小屋 → 开始使用」；
3. 第 1 步「目标用户与平台」点刷新，核对平台、Bot 账号、私聊对象；
4. 确认这个窗口用于**管理员指令 + 主动消息投递**。

确认后插件会自动创建该私聊的精确目标、绑定人格，并启用共享宿主。之后这个窗口就是你的管理员窗口。

> 如果你之前手动改过 `multi_host.targets`，请保证**只有一个精确私聊目标**对应当前核心管理员；多个精确目标会让向导要求补充确认。

## 3. 配置插件模型

「开始使用」第 2 步「插件模型」：

- 选一个文本 Provider 作为插件内部任务模型（主动联系、日程、每日反思等）；
- 可给「主动联系」「日程」单独指定路由；
- 日常聊天模型不在这里改，仍在 AstrBot 主链配置。

保存后点「完成」。

## 4. 走完其余向导步骤

| 步骤 | 做什么 | 能否跳过 |
| --- | --- | --- |
| 世界知识 | 给角色补充世界观/设定资料 | 可以 |
| 关系教学 | 主要陪伴对象的称呼、关系、相处方式（只作用于这段私聊） | 建议填 |
| 主动功能与强度 | 是否主动开口、频率、每日上限、免打扰时段 | 建议填 |
| 日程与观察 | 角色一天的生活节奏，主动联系更有由头 | 可以 |
| 群聊配置 | 角色进群时的参与方式、唤醒、插话 | 不进群可跳过 |

每步改完保存，再点「完成」；跳过的步骤会记为已跳过，不影响基础聊天。

## 5. 跑一次主动消息测试

1. 勾选「我同意当前版本向已绑定的管理员私聊发送一次主动联系测试」；
2. 点「重新运行主动联系」；
3. 手机上收到一条主动消息即通过，向导变为完成。

常见失败：

| 失败码 | 处理 |
| --- | --- |
| `authorization_revoked` | 该窗口的主动联系授权被收回：去「关系与权限 → 用户 → 权限」重新开启主动联系，再测 |
| `core.authorization.denied` / `authorization_denied` | 先确认 AstrBot 达到 4.27.2，再分别核对 Dashboard 当前账号的管理权限与 QQ 核心管理员私聊窗口绑定；更新插件或重复绑定窗口不能代替升级 AstrBot |
| `model_task_unregistered` | 到「模型与连接」给 `proactive.compose` 配模型 |
| 配置未启用 | 回第 5 步确认主动联系总开关与目的开关 |
| `Token 过期`（页面） | 面板登录超过 7 天：刷新或重新登录 |

## 6. 日常入口

- **陪伴小屋**：首页、状态、日记、生活观察、家具与能力；
- **管理 → 模型与连接**：任务模型、搜索服务；
- **管理 → 决策**：群聊回应、主动节奏、防骚扰；
- **管理 → 表达**：文字风格、语音、表情与配图；
- **管理 → 学习/反思**：表达学习、成长链路、每日复盘；
- **管理 → 关系与权限**：用户/群聊目录、新用户默认权限、主动联系授权、黑名单；
- **管理 → 治理与维护**：诊断、缓存、提示词；
- **管理 → 资料与维护**：存储、备份、迁移；
- **手机连接**：需要手机陪伴终端时在这里配对（可选）。

## 7. 群聊（可选）

1. 「关系与权限 → 群聊」或「账号与会话」添加群目标；
2. 「管理 → 决策 → 群聊参与」设置被叫到时怎么接、是否观察、是否主动插话；
3. 群里 @ 它或叫名字即可触发；私聊配置不受影响。

## 8. 数据与升级

- 插件数据在 `data/plugin_data/astrbot_plugin_private_companion`，**不在插件代码目录**；
- 升级插件只替换代码，数据会保留；
- 迁移机器时先做「资料与维护 → 备份」，再在新机器恢复；
- 不要把旧版插件目录里的 `data/` 手动搬进新代码目录。

## 首次使用最容易踩的坑

1. 没发绑定指令：只装插件不绑定，向导第 1 步会一直等你；
2. 绑定了但主动权限被收：第 8 步会报 `authorization_revoked`；
3. 插件模型没配：日常聊天正常，但主动联系/日程全失败；
4. 面板登录超过 7 天：插件页面显示 `Token 过期`，重新登录即可；
5. AstrBot 4.29.4 页面 404：见 issue #555，先确认 Web API 是否注册成功。
