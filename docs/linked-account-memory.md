# 关联账号长期记忆联动

## 行为

长期记忆有独立的共享开关，默认关闭，不跟随聊天上下文或身份权限开关。
在「关系与权限 → 关联账号」开启后，可选择：

- 仅开启后的记忆：其他成员的记忆必须同时满足创建时间、发生时间不早于本次授权。带摘要起始时间的跨界摘要也不开放。
- 包含已有历史记忆：需要单独确认；仍须满足原窗口、原生 Bot 账号和人格的来源校验。

当前账号原有记忆不受跨账号时间下限限制。因此，A 和 B 自己能看的旧记忆数量可以不同；每一方的统计和召回使用同一个授权谓词。
关闭、解除关联或成员变更后，旧授权失效。增减成员时，旧客户端不提供新授权则自动关闭共享；新客户端必须重新确认。重新开启会建立新的时间下限。

## 信任边界

陪伴插件保存关联组和独立授权，记忆插件保存原始记忆。读取不合并用户 ID，不重写主体、原窗口、原账号，不复制记忆，也不改变写入流程。

宿主为 read/summary 签发仅本进程可用的对象租约，绑定注册实例、原请求身份、目的、关联版本、成员范围和原生人格，30 秒失效，最多保留 128 个。JSON、提示词或模型工具参数不能构造租约；这不是针对任意不可信 Python 插件的进程沙箱。
记忆插件只通过宿主注册表验证租约，读取前后都校验，并检查记忆/ACL revision 未在等待期间改变；宿主在接收结果和组装提示词时再次校验。卸载、替换注册、权限/人格/成员变化和过期均会拒绝旧结果。

查询严格匹配原生会话窗口、原生登录账号和记录的人格，只读取已进入 stable_memory 的长期记忆，排除其他群、内部、待审核、原始事件、归档、失效记录及显式记忆 ACL 拒绝。内部 Bot ID 与原生账号不同，不能混用。无法证明来源的旧记忆不推断归属，不自动补写或迁移。
召回返回不透明记录 ID 和原窗口/用户/原生 Bot 来源。统计使用同一 SQL 授权谓词，但不受单次返回条数或提示词字符上限限制。
撤权阻止后续跨账号读取，不撤回已经发送的消息，也不声称抹除已产生的模型输出。

## 兼容

两个插件需要配套升级。记忆 provider 显式声明 `linked_memory_read=True`。旧 provider 未开启共享时仍收到原有可 JSON 序列化的请求；开启共享时拒绝交给不支持撤权协议的旧 provider。
新记忆插件遇到没有范围租约协议的旧宿主不会降级为按裸用户 ID 查询；其独立记忆功能和原始数据不受此适配改写。此能力接在共享宿主的 read/summary 联动入口，不扩展旧版 bridge 的授权能力。
安装不会自动打开共享，不迁移数据库、不重写历史。建议两个包一起更新后重载，再在关联页选择授权范围。

## 自动验收

测试只使用合成账号和临时 SQLite；不连接服务器、真实账号、模型或生产记忆。

陪伴插件：

```sh
python -m unittest -q tests.test_linked_memory_access tests.test_private_account_links
node --test tests/test_account_link_editor.cjs
```

两个真实源码树的核心联动（在记忆插件目录，指定陪伴插件源码树）：

```sh
PRIVATE_COMPANION_CHECKOUT=/path/to/private-companion python -m unittest -q tests.test_linked_memory_store tests.test_linked_memory_integration
```

带 AstrBot SDK 的真实共享宿主 → 记忆插件存储 → 提示词及统计链（在陪伴插件目录）：

```sh
MEMORY_COMPANION_CHECKOUT=/path/to/memory-companion python -c 'import tests.astrbot_data_root; import unittest; unittest.main(module=None)' -q tests.test_linked_memory_host
```

上述外部路径均是源码检查用环境变量，不进入生产配置。未提供另一个源码树时，跨仓库用例明确跳过，不能把跳过当通过。对话输入、网络平台投递和生产环境升级仍需单独验收。


### 微信原生身份与旧摘要

适配器实例 ID 只用于路由，不能代替微信登录 ID。宿主从当前适配器取得登录身份，
同时验证账号限定的原生私聊会话；登录身份变化后，已有读取授权失效。

旧版会话摘要缺少人格或使用 `self` 占位归属时，读取方逐条核对摘要引用的全部来源事件。
只有来源完整、私聊窗口、原生登录账号、参与者和人格一致，才可在当前授权范围中读取。
明确属于其他人格或账号的记录不会被覆盖；来源缺失或冲突时不共享。
读取和统计使用同一过滤条件，保留原始记录、原会话和原归属，不迁移或复制旧记忆。
