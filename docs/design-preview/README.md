# 功能地图文字原型

这是按「旧版分类（V2 当前 13 类，不含实验）+ 资料/功能/数据/工具分开 + 卡片进入详情」做的可点击原型。

当前有 **69 张卡**，覆盖旧版大部分 P0/P1 能力；剩余对照见 `V1_COVERAGE_AUDIT.md`。

打开 `index.html` 即可，不需要构建或后端。

## 可试的交互

- 左侧 14 类跳转分区
- 顶部按“功能 / 资料 / 数据 / 工具 / 视图”筛选
- 私聊、群聊、观察的分区切换
- 点击任意卡片进入详情
- 详情里的开关、下拉、滑杆、相关入口
- `Ctrl / ⌘ K` 搜索功能、资料和设置
- 右上角切换深浅色
- 窄屏下左侧栏收起

## 直接看某个详情

```text
index.html?card=contact       主动联系
index.html?card=persona       人格档案
index.html?card=boundary      关系与边界
index.html?card=total         Token 总消耗
```
