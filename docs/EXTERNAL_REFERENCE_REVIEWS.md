# 外部参考汇总

> 统一入口：外部产品和项目的参考结论集中在这里；不为每一份参考单独增加设计入口。各条记录区分用户提供、页面观察、独立核验和设计提议，不能把外部宣传或演示当作本框架运行证据。

## HDSI（HDS-Interlude）

来源：用户提供的 HDSI 开发说明及项目链接 <https://github.com/MomoiCore/HDS-Interlude>。本次 GitHub API 对该仓库返回 404，代码和完整设计文档未独立核验；以下机制来自用户提供的一手说明。

HDSI 的拟真性能优秀，根本原因是把对话从“用户输入后的回答”改成“持续生活剧本中的事件反应”。角色拥有自身活动、烦恼、关系、情绪和未完成事项，能够主动分享、倾诉、吐槽或暂时保持沉默。`overlay` 使习惯、人格、关系和价值观逐步变化，持久经历让长期交流增加个体化证据；`alter system` 使同一文字在玩笑、认真请求、试探或情绪表达下产生不同回应；稀疏自动推进让角色在用户离开时仍有生活；共用剧本让所有用户面对同一个角色和世界，而不是独立副本。

对新框架的吸收：

- 持续剧本落到 `PersonaWorldModel`、`ActivityProcess`、`WorldEvent` 和 checkpoint；用户消息是世界事件，不是唯一上下文。
- overlay 拆成 world、persona、relationship、user preference、session 五层，各自有 owner、来源、revision、TTL、purpose 和可见性。
- alter 落到 `IntentGraph`、`MotivePlan`、情绪/关系投影和 `ConversationOccupancy`，由模型理解语义，由代码校验权限和动作。
- 自动推进使用活动边界和 `next_checkpoint_at`，不按分钟调用模型；活动、投影、队列和摘要共享 Runtime 总预算。
- 共用剧本对应 `global`，用户偏好对应 `user`，当前话题和打断原因对应 `session`。global 共享角色世界，不能共享用户私聊正文、健康、位置或私密证据。

“越聊越好”只有在有效经历沉淀、正确 overlay 更新、精确召回和纠正传播同时成立时才成立；错误事实累积、Prompt 膨胀、越权共享和后台空转会抵消收益。后续应测偏好命中、证据覆盖、错误记忆率、纠正失效延迟、隐私泄露、首句延迟、模型调用和峰值 RSS。

## 小黑盒分享链接

来源：用户提供的小黑盒分享 URL。网页只返回前端壳，正文未进入 HTML；`/bbs/app/link/tree` 系列接口返回失败，因此帖子正文、作者和观点均为 `unknown`。可观察到的只是异步链接解析和网页/原生打开路径。

对新框架的吸收：分享 URL 建模为 `ShareProjection` 的外部不透明引用，而不是 Memory、WorldEntity 或作品主键。解析、渲染和投递分层；网页、原生、嵌入和 Bot 消息是不同适配器。分享视图按受众、ACL、revision、过期、撤回和 UTF-8 字节预算裁剪，可选择实时投影或明确固定的快照。原生打开失败要降级到网页并保留 `unknown/unavailable/expired/permission_denied` 回执，不能把生成 deep link 当作已打开。

分享不是第四种共享模式：session 分享只面向原会话或受邀目标，user 分享仍需按私聊/群聊复核，global 分享只面向显式公共分区。传播参数、统计会话和平台原始 ID不能改变共享归属或成为可迁移身份。

## 统一采用规则

两份参考共同支持“持续世界 + 有界投影 + 明确回执”的方向，但不引入各自的界面、文案、关键词或隐式权限。外部机制进入框架时必须回写对应领域文档、契约和验收案例；只有出现新的独立 owner 或协议责任时，才新增文档。
