# 陪伴小屋：资料 / 功能分类与卡片设计稿

版本：2026-11-02<br>
性质：文字设计稿，不包含实现代码<br>
分类：沿用旧版分类，但 V2 当前没有“实验”这一组<br>
核心修正：先区分“资料”“功能”“数据/工具”，再谈卡片和详情

---

## 0. 先纠正一个分类错误

`世界知识` 不是功能。

它是 **资料**：

- 人格
- 世界观
- 用户与关系资料
- 角色背景

它没有“开启 / 关闭”，只有：

- 内容是什么
- 来源是什么
- 版本是什么
- 谁在引用它

同样：

```text
总览      → 视图，不是功能
书柜      → 资料/内容库，不是功能
Token     → 数据报表，不是功能
排障      → 工具，不是功能
观察记录  → 资料，不是功能
```

如果把这些都叫“功能”，卡片上就会出现“世界知识：已开启”这种错误表达。

---

## 1. 三种内容类型

### 1.1 功能

有行为、有开关、有配置、有状态。

例如：

```text
主动联系
语音合成
学习
QQ空间发布
私聊边界
群聊边界
```

卡片显示：

```text
已开启 / 已关闭 / 未配置 / 不可用
[配置]
```

### 1.2 资料

有内容、有来源、有版本，没有“启用/停用”。

例如：

```text
世界知识
人格档案
用户与关系资料
私聊对象档案
群聊档案
观察记录
记忆
书柜作品
```

卡片显示：

```text
资料类型
条目数量
最后更新
来源
[查看 / 编辑]
```

不显示：

```text
已开启
已关闭
启用
停用
```

### 1.3 数据与工具

只读数据或一次性动作。

例如：

```text
总览
Token 消耗
运行诊断
错误记录
配置检查
```

卡片显示：

```text
指标 / 状态 / 最近一次
[查看明细]
[运行诊断]
```

没有“开启/关闭”的含义。

### 3.2 资料型分类的页面

以 `02 世界知识` 为例：

```text
世界知识
TA 是谁，从哪里来。

[资料] [功能]

资料：
  [人格档案]
  星缘 · 温和、慢热、短句
  版本 3 · 更新于 10-31
  [查看]

  [世界观]
  现代都市，临海小城
  版本 2 · 来源：角色编辑
  [查看]

  [用户与关系资料]
  TA 怎么理解你和其他人
  12 条 · 最近更新 10-31
  [查看]

功能：
  [创建人格]
  从零描述、问答引导或导入现有资料
  [开始]

  [拟人优化]
  找出机械感、重复和不合人设的地方
  [分析]
```

`人格问卷` 不再作为一级入口，而是“创建人格”里的一种方式；<br>
`创建人格` 负责产生新人格，`拟人优化` 负责优化现有人格。

没有：

```text
已开启
已关闭
启用
停用
```

主按钮：

```text
[编辑资料]
[导入]
[导出]
```

以 `07 主动` 为例：

### 3.5 总览不是功能

```text

```

没有“总览功能已开启”。

### 3.6 书柜是资料

`08 书柜` 不写“书柜已开启”。

```text
书柜
你们留下的作品和文字。

[作品]      12 件
[私密日记]  8 篇
[夹层阅读]  3 本
```

主按钮：

```text
[开始创作]
[查看全部]
```

生成能力、模型、审核属于 `13 模型` 或 `12 配置`，不在书柜里重复放开关。

### 3.7 Token 是数据

`10 Token` 不写“Token 已开启”。

```text
Token

较上月     +12%
预算       2,000,000

[按任务] [按模型] [预算与预警]
```

### 3.8 排障是工具

`11 排障` 不写“排障已开启”。

```text
排障

[最近错误] 无
[配置检查] 通过
[目标检查] 通过

[运行诊断]
[复制诊断信息]
```

## 4. 卡片系统：不要用同一种卡片硬套

### 4.1 功能卡

```text
┌────────────────────────────┐
│ [图标]              已开启 │
│                            │
│ 主动联系                   │
│ TA 会不会主动开口          │
│                            │
│ 跟随角色 · 更新 10-31      │
│                       →    │
└────────────────────────────┘
```

点击进入功能详情。

### 4.2 资料卡

```text
┌────────────────────────────┐
│ [图标]              资料   │
│                            │
│ 人格档案                   │
│ 星缘 · 温和、慢热、短句    │
│                            │
│ 版本 3 · 更新 10-31        │
│                       →    │
└────────────────────────────┘
```

没有状态开关，只有“资料”标记。

### 4.3 数据卡

```text
┌────────────────────────────┐
│ 本月消耗            数据   │
│ 1,240,000                  │
│ 较上月 +12%                │
│                       →    │
└────────────────────────────┘
```

### 4.4 工具卡

```text
┌────────────────────────────┐
│ 运行诊断            工具   │
│ 上次运行：今天 14:20       │
│ 6 项检查 · 1 项注意        │
│                  [运行]    │
└────────────────────────────┘
```

### 4.5 卡片规则

- 功能卡：状态 + 进入配置
- 资料卡：类型 + 内容摘要 + 进入查看/编辑
- 数据卡：指标 + 进入明细
- 工具卡：状态 + 运行动作
- 卡片上不放开/关开关
- 卡片上不放危险操作
- 卡片不混用“已开启”与“资料”

## 6. 资料与功能的边界

### 6.1 资料可以被功能引用，但不在功能里编辑

例如：

```text
人格档案（资料）
  ↑ 被引用
主动联系（功能）
```

主动详情只显示：

```text
使用的人格：星缘
```

不在这里编辑人格。

### 6.2 功能的配置不改资料内容

例如：

```text
语音合成（功能）
  音色、模型、语速

人格档案（资料）
  性格、说话方式
```

语音详情不改人格。

### 6.3 一个设置只有一个可编辑入口

```text
语音音色 → 只在「模型 → 语音合成」编辑
人格语气 → 只在「世界知识 → 人格档案」编辑
主动频率 → 只在「主动 → 联系节奏」编辑
```

其他位置只读显示来源。

## 8. 视觉规范

### 8.1 卡片类型标识

- 功能：状态点 + 状态文字
- 资料：`资料` 小标签，无状态点
- 数据：`数据` 小标签
- 工具：`工具` 小标签

标签颜色低饱和，不抢标题。

### 8.2 分区头

```text
02 世界知识
资料 · 3 项
TA 是谁，从哪里来。
```

```text
07 主动
功能 · 3 项
TA 会在什么时候来找你。
```

### 8.3 混合分类的切换

```text
私聊
[资料] [功能]
```

用分段控件，不用两个页面。

### 8.4 卡片网格

```text
桌面 3 列
平板 2 列
手机 1 列
```

### 8.5 详情布局

```text
主内容 760px
右侧状态 280px
手机单列
```

## 12. 设计决策摘要

1. **先分类型，再分类。**
2. **世界知识、书柜是资料，不是功能。**
3. **总览是视图，Token 是数据，排障是工具。**
4. **功能卡有状态，资料卡没有启用/停用。**
5. **一个设置只有一个可编辑入口。**

这份稿子先修正分类语义；确认后再做逐页线框和实现。
